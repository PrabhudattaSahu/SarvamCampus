StudyNotes Studio

Turn handwritten PDFs into complete, multilingual study kits — as a single desktop app.

View on GitHub Read the docs
Python 3.12 MIT licensed Windows · Linux · macOS Runs offline English + 12 Indian languages

Handwriting in, study kit out

Give it the messy stuff — a PDF of handwritten lecture notes. Get back a complete study kit, written in the language you choose.

📥 Upload everything at once

Select all your PDFs in one go — they become a single study kit, filed under a subject.

📝 Structured notes

Titled sections with bullet points and a short detail paragraph, in your target language.

⚡ Short notes

Crisp, exam-eve revision bullets distilled from the full notes.

🃏 Flashcards

Active-recall front/back cards for every key term and fact.

❓ Quiz

Multiple-choice questions with answers and explanations.

🔊 Audio overview

A spoken narration you can play in-app, generated from your notes.

Organise your topics properly

  • Edit any topic — rename, edit points and detail, add tags.
  • Drag to reorder topics, or use the ↑ / ↓ buttons.
  • Merge, delete or add topics freely.
  • Smart organise — let the model put topics in the best learning order.
  • Search across every topic in every document.
  • Group into subjects — and move documents around any time.
  • Export any kit as Markdown, HTML or JSON.

How it works

PDF(s) ──► rasterise ──► OCR ──► structure ──┬─► short notes
(PyMuPDF) (provider) (LLM) ├─► flashcards
├─► quiz
└─► audio script ──► TTS ──► audio

OCR, LLM and TTS each sit behind a swappable interface, so you can point it at OpenAI, Sarvam AI, Groq, or a local model. With mock providers it runs fully offline.

Get started

git clone https://github.com/<your-username>/studynotes-studio.git
cd studynotes-studio
pip install -r requirements.txt
python launcher.py

On Windows, build the executable with build\build_windows.bat, or let the included GitHub Actions workflow build it for you.
